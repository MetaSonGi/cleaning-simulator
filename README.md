# 🧽 싹싹 청소 시뮬레이터

문질러 문질러! 더러운 물건의 때를 벗겨내는 만족감형 원터치 청소 게임입니다.
손가락(모바일)이나 마우스(PC)로 드래그해서 때를 지우면 깨끗한 밑그림이 드러납니다.

## 🎮 플레이 방법

1. 스테이지 선택 화면에서 원하는 스테이지를 고르세요.
2. 손가락 또는 마우스로 **드래그**해서 때를 문질러 지우세요.
3. **진한 얼룩은 여러 번 문질러야** 지워집니다 (옅은 때 1회 → 진한 때 2~3회).
4. 청소 진행률이 **100%**가 되면 스테이지 클리어!
5. 빨리 깰수록 별을 많이 받습니다 (3★/2★/1★, 시간 기준).

## 🧽 스테이지 (5개)

| # | 스테이지 | 특징 |
|---|---------|------|
| 1 | 🪟 뽀득뽀득 유리창 | 먼지 낀 창문 닦기 (튜토리얼) |
| 2 | 🍳 기름때 낀 프라이팬 | 기름때 + 눌어붙은 탄 자국 |
| 3 | ☕ 얼룩덜룩 카펫 | 커피 얼룩 + 끈적이는 잼 자국(3회) |
| 4 | 🚗 진흙탕 자동차 | 진흙 튄 자동차 닦기 |
| 5 | 🚿 곰팡이 핀 욕실 | 곰팡이(3회) + 비누때, 가장 넓은 면적 |

## ⚙️ 기능

- 스폰지 크기 조절 (소/중/대)
- 실시간 청소 진행률 % + 타이머
- 스테이지별 최고 별점 기록 (localStorage 저장)
- WebAudio 기반 효과음 (문지르는 소리·클리어 팡파레, 켜기/끄기 가능)
- 모바일 터치 + PC 마우스 모두 지원, 반응형 레이아웃

## 🛠 기술

- 단일 `index.html` 파일 (CSS/JS 인라인, 외부 의존성 없음)
- 때 제거: offscreen canvas 마스크 + 셀 단위 경도(hardness) 그리드 방식
  - 셀마다 1~3의 내구도를 가지고, 문지를 때마다 1씩 감소 (쿨다운 110ms)
  - 진행률 = 남은 내구도 합 / 전체 내구도 합으로 정확히 계산
- 부드러운 문지르기: `getCoalescedEvents()` + 경로 보간 스탬프
